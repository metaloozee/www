# Ditto

Ditto is a durable AI coding workspace on the web. Each GitHub repo gets its own sandbox with parallel sessions: isolated git worktrees, resumable agent runs over SSE, a tRPC control plane, and D1/R2-backed state. Agents and humans share a real commit-to-PR workflow instead of throwaway generations.

- **Type:** AI coding workspace
- **Stack:** TanStack Start, Cloudflare Workers, D1, R2, Sandbox SDK
- **Year:** 2026
- **Status:** Still under active development
- **Repo:** [metaloozee/ditto](https://github.com/metaloozee/ditto)
