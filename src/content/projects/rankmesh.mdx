# RankMesh

RankMesh automates SEO and AI-search visibility. Agents do the execution: they audit, fix, write, and publish. People stay in review and approve.

- **Type:** Autonomous SEO and GEO engine
- **Role:** AI Engineer Intern at Ocavior, May 2026 to present
- **Stack:** FastAPI, Celery/Redis, LangChain, Next.js, PostgreSQL, R2
- **Site:** [rankmesh.ai](https://rankmesh.ai)

## Architecture

The backend is multi-service FastAPI: an orchestrator for projects, RAG, blogs, SEO, marketing, scheduling, and billing, plus specialist agents for SEO/GEO, prompts, and posts. Long jobs run on Celery/Redis with Claude and Codex runners. The panel is Next.js with client and manager workspaces and Meshy as the chat operator.

## What I built

I've worked almost entirely inside this product, on both the agent backend and the panel operators use. This is what I ship day to day.

- Shipped across the FastAPI multi-service backend: project auth, ingestion and RAG routing, blogs, SEO, marketing workflows, scheduling, credits, billing, and activity feeds.
- Built and hardened Celery/Redis autonomous execution with Claude and Codex runners, capacity leases, audit to fix-plan to schedule, and manager pause/resume/cancel.
- Owned large slices of the Next.js panel rewrite: client and manager workspaces, Meshy project chat with SSE, Discover and Manage SEO, admin tooling, and the performance work that kept data-heavy polls usable as agent output grew.
- Wired Search Console, Analytics, Firecrawl, CMS and GitHub publish gates, R2 storage, and review-first content release.
